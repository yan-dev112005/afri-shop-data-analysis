# 🛒 AFRI-SHOP — Analyse des données e-commerce

## 📌 Présentation du projet

AFRI-SHOP est un projet d'analyse de données réalisé sur une activité e-commerce en Afrique de l'Ouest.

L'objectif de ce projet est d'exploiter les données commerciales afin d'évaluer la performance de l'entreprise, d'identifier les principaux moteurs du chiffre d'affaires et de formuler des recommandations basées sur les données.

---

## 🎯 Objectifs

Cette analyse cherche notamment à :

* Analyser le chiffre d'affaires et le bénéfice
* Identifier les périodes les plus performantes
* Étudier les méthodes de paiement
* Analyser les statuts des commandes
* Comparer les performances par pays
* Évaluer les différents canaux de vente
* Analyser les catégories et produits
* Construire un dashboard avec les principaux KPIs
* Formuler des recommandations business

---

## 🗂️ Données

Le projet utilise plusieurs tables contenant notamment des informations sur :

* 👤 Les clients
* 📦 Les produits
* 🛍️ Les commandes
* 🧾 Les articles commandés
* 💳 Les paiements

Le dataset contient **12 500 commandes**, **4 220 clients**, **30 produits** et **20 576 lignes d'articles de commande**.

---

## 🛠️ Technologies utilisées

* **Python**
* **Pandas** — manipulation et analyse des données
* **Matplotlib** — visualisation des données

## 🔎 Analyses réalisées

### 📅 Performance mensuelle

L'analyse temporelle permet d'identifier les périodes de forte et faible performance.

**Meilleur mois : Mai 2025**

* Chiffre d'affaires : **296 884 $**
* Bénéfice : **78 821 $**
* Commandes : **740**

### 💳 Méthodes de paiement

Mobile Money constitue le principal moyen de paiement avec environ **44,90 % du chiffre d'affaires**.

Les marges restent relativement proches entre les différentes méthodes de paiement.

### 📦 Statuts des commandes

Les commandes **Completed** représentent environ **80,74 % du chiffre d'affaires**.

Les commandes Pending, Cancelled et Returned représentent ensemble environ **19,08 % des commandes**, ce qui constitue un axe d'amélioration à surveiller.

### 🌍 Performance par pays

La **Côte d'Ivoire** est le marché générant le plus de chiffre d'affaires, suivie du Nigeria et du Bénin.

### 🛍️ Canaux de vente

Le **site web** est le principal canal de vente avec environ **46,94 % du chiffre d'affaires**.

WhatsApp arrive en deuxième position.

## 💡 Principaux insights

L'analyse met en évidence plusieurs éléments importants :

1. **Mai 2025** est le mois le plus performant.
2. **Mobile Money** domine les moyens de paiement.
3. Le **site web** constitue le principal canal de vente.
4. La **Côte d'Ivoire** représente le marché le plus performant.
5. La marge globale est relativement stable autour de **27 %**.
6. Les commandes non finalisées représentent un axe d'amélioration potentiel.

---

## 🎯 Recommandations business

À partir des résultats obtenus, plusieurs actions peuvent être envisagées :

* Optimiser le site web afin de maintenir son niveau de performance.
* Maintenir et développer le paiement par Mobile Money.
* Réduire les commandes annulées et retournées.
* Renforcer la présence commerciale sur les marchés les plus performants.
* Étudier les facteurs ayant contribué à la forte performance de mai 2025.
